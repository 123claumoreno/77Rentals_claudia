# Fonts

Both are free to download. Install them on your computer, or load them from
the web in HTML pieces.

- **Fraunces** (headings, weight 400): https://fonts.google.com/specimen/Fraunces
- **General Sans** (body text, weights 400, 500, 600): https://www.fontshare.com/fonts/general-sans

For HTML, add these two lines to the `<head>`:

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Fraunces:opsz,wght@9..144,400;9..144,500&display=swap">
<link rel="stylesheet" href="https://api.fontshare.com/v2/css?f[]=general-sans@400,500,600&display=swap">
```

# 77Rentals – Marketing Assets

Posters, videos, and listing content for 77Rentals.

## Structure
- `brand/` – logos, fonts, color palette (single source of truth)
- `posters/templates/` – reusable poster layouts; `posters/exports/` – finished files
- `videos/scripts/` – shot lists and captions; `videos/exports/` – finished videos
- `listings/` – one folder or file per property (details, copy, photo links)
- `assets/photos/` – raw property photos (large files: consider Drive/Canva and link them here)

## Listing naming
`listings/<address-or-unit>/` e.g. `listings/77-main-st-unit-2/`
